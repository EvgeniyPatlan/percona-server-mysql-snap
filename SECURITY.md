# Security policy

## What qualifies as a security issue

Credentials leakage, outdated dependencies with known vulnerabilities, and
other issues that could lead to unprivileged or unauthorized access to the
database or the system.

## Reporting a vulnerability

Please report security issues privately through
[GitHub](https://github.com/EvgeniyPatlan/percona-server-mysql-snap/security/advisories/new).
See [Privately reporting a security vulnerability](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)
for instructions.

Do not open public issues for suspected vulnerabilities.
